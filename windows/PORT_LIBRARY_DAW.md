# Writer, Librarian, ABC/MIDI и экспорт DAW на Windows

Это часть локальной ветки `full-windows-port`. Данные пользователя остаются в
папках проекта. Эти модули не устанавливают модели, не обращаются к облачным API
и не запускают установленную DAW.

| Возможность | Реализация и проверка |
| --- | --- |
| Writer: документы, Markdown-заметки, параметры и связанные takes | Сохранён исходный формат. Проверены Unicode и закрытие файлов до атомарной замены JSON в Windows. |
| Writer: autosave, snapshot, история и восстановление | Проверены интервалы autosave и восстановление с сохранением предыдущей версии, лимит 100 версий. |
| Writer: резервная копия и корзина | Импорт не перезаписывает документы: конфликт становится отдельной копией. Проверены повторный импорт и сохранение документов из корзины. |
| Librarian: коллекции, подразделы, оценки, заметки, pins, favorites | Сохранены исходные операции и каталог; проверены блокировки и freeze. Поиск и переключение favorites выполняются существующими интерфейсом/API. |
| Librarian: корзина и восстановление | Проверены реальные перемещения синтетических файлов с русскими именами. Пути `..`, drive/UNC и выход через junction отклоняются. |
| Librarian: ZIP выгрузка | Реальная WAV-выгрузка проверена. Имена безопасны для Windows и различаются без учёта регистра. Неудачная работа не оставляет готовый частичный архив. |
| MIDI → ABC | Проверены импорт двух голосов, каналы, PPQ, grid, обратная проверка нот и снятие аккордов без изменения мелодии. MIDI формата 0/1, до 32 MiB, без SMPTE. Повреждённые файлы отклоняются. |
| REAPER | Создаётся настоящий ZIP с RPP, mix/stems, MIDI-голосами, текстом на временной шкале и маркерами разделов при наличии тайминга. Проверены структура RPP и относительные пути ZIP. |
| DAWproject | Создаётся архив project.xml, metadata.xml и WAV. Проверены разбор XML, ноты и наличие всех файлов из относительных ссылок. Неудачный повторный экспорт сохраняет предыдущий результат. |
| Обнаружение DAW | Добавлены Windows-папки REAPER, Waveform и Bitwig, PATH и hostname. Программа не запускается для определения версии. Неизвестная версия остаётся пустой; архитектура Waveform64 не считается номером версии. |

48 kHz PCM WAV, который пишет нативный движок, преобразуется в stereo 24-bit WAV
стандартной библиотекой Python: поддержаны mono/stereo и исходные 16/24/32-bit PCM.
Проверены точные значения положительных и отрицательных отсчётов, копирование
24-bit и дублирование моно в стерео. Для такого экспорта FFmpeg не нужен.

Для MP3/FLAC, float WAV, другой частоты дискретизации, многоканального источника
или FLAC-выгрузки нужен согласованный локальный FFmpeg. В этом этапе проверен
контракт вызова через mock; внешний конвертер не устанавливался и не запускался.
В DAW-экспорте процессы FFmpeg получают среду проекта и timeout через общий native runtime.

Экспорт DAW остаётся экспериментальным: открытие этих файлов настоящими REAPER,
Waveform, Bitwig или другой DAW в данном этапе не проверялось. XML и ссылки
проверены локально; полная проверка XSD и поведения конкретных DAW не заявляется.

Локальная чат-модель Writer относится к C++ движку и интерфейсу; notebook-модуль
не скачивает и не запускает LLM. Отсутствие модели не мешает редактированию документов.

## Проверка

Из корня ветки, без дополнительных Python-пакетов:

```powershell
py -3.10 -W error::ResourceWarning -m unittest discover -s lab -p test_windows_library.py -v
```

21 тест прошёл на Windows с установленным Python 3.10 и Python 3.14.
Данные создаются только под `windows/cache/tests` и удаляются самими тестами.
Рабочие модели, музыка и исходная базовая установка не используются.

Тесты настоящих PCM/ZIP/XML/RPP не вызывают внешних конвертеров. Только fallback
для сжатого аудио, конверсионная ошибка и отказ атомарной замены проверяются mocks.
Тест junction использует встроенный Windows mklink в собственных временных папках.

Лицензии исходного проекта сохранены. `abc_tools.py` не изменён, его существующая
атрибуция Apache License 2.0 сохранена. Новый код этих модулей не добавляет пакетов,
моделей или лицензий внешних конвертеров к установке.
